## Rules that bit us (keep them)

- **Check `git branch --show-current` before every commit.** A commit once landed on another agent's branch.
- **Rebuild shared before OpenAPI:** run `pnpm --filter @agency-os/shared build` before `cd backend && pnpm openapi:update`. Otherwise the snapshot comes from a stale shared `dist` and the contracts test fails.
- **zod 4 gotchas:**
  - `.partial()` applies inner `.default()` values;
  - `.default()` takes the output value, so place it before `.transform`;
  - `.uuid()` checks RFC version and variant bits;
  - `extendZodWithOpenApi` does not reach schemas created before it runs, so clone them.
- **Concurrency tests:** they are only deterministic if a third connection holds `SELECT … FOR UPDATE` while both transitions start. Race pairs that are both valid from the start status.
- **Dates:** business dates are Bogota calendar dates, never `toISOString().slice(0, 10)`.
- **Architecture lint:** adding a schema import to a module with a listed exception means updating `backend/architecture-baseline.json`.
- **Migrations:** every new migration needs its `_journal.json` entry. Run `TEST_DB_RECREATE=1 pnpm ci:database` after editing an applied migration.
- **Delivery:** about 400 changed lines per PR, stacked on the previous one, with a Chain Context table. Never push or open a PR without the user's OK. RDD is off globally.
