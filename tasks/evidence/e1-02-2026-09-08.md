# E1-02 — restauración web ante fallo transitorio · 2026-09-08

Estado: corrección implementada en el árbol de trabajo; pendiente de commit para el cierre formal.

## Resultado

`AuthProvider` distingue un 401 definitivo de un fallo transitorio de refresh o `/auth/me`.
Los fallos transitorios muestran un estado recuperable con botón de reintento y conservan la
cookie/token existente; las vistas protegidas no se renderizan hasta validar el usuario. Las
restauraciones usan un contador de intento y una marca de montaje para ignorar respuestas de
requests cancelados u obsoletos.

navegador mostró el panel `Estamos verificando tu acceso`, el mensaje de conexión y el botón
