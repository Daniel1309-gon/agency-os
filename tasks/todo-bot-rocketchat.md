# Checklist: piloto del bot de Rocket.Chat

- [ ] Contrato nativo y proveedor FAQ con pruebas unitarias.
- [ ] Validación segura del webhook y respuesta `200` para eventos descartados.
- [ ] Rate limit Redis, deduplicación e integración outbox.
- [ ] Cinco FAQ JSON versionadas e importador administrativo temporal.
- [ ] Scripts locales de migración, runtime, IP bootstrap, seed y arranque.
- [ ] Gates backend y web-app ejecutados desde sus proyectos independientes.
- [ ] Revisión de seguridad, secretos, logs y diff final.
